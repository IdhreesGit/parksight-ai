# ParkSight AI – AI-Powered Smart Parking Solution

## About the Project

ParkSight AI is an AI Immersion project that explores how computer vision can help drivers find available parking spaces more efficiently.

The project demonstrates a prototype parking dashboard using simulated parking data.

## Problem Statement

Drivers spend unnecessary time searching for available parking spaces because real-time parking occupancy is not visible to them.

## Proposed Solution

ParkSight AI uses the concept of computer vision to detect parking occupancy and present available spaces through a web interface.

The prototype demonstrates:

- Parking space availability
- Occupancy visualization
- Simulated live updates
- AI-inspired parking recommendation
- Parking analytics
- User-friendly dashboard

## AI and Technology

- Computer Vision
- YOLO concept
- React
- TypeScript
- Vite
- Tailwind CSS

## Prototype Limitation

This version is an interactive prototype using simulated parking data.

It does not currently use live CCTV input, real-time vehicle detection, trained-model inference, GPS navigation, or a backend parking database.

The prototype is intended to demonstrate the proposed AI-powered solution and user experience.

## Field Observation

The problem was observed at Coimbatore Railway Junction as part of the AI Immersion Design Thinking activity.
